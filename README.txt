국방예산 웹 대시보드

실행: index.html을 브라우저에서 여세요. 인터넷 연결이나 설치가 필요 없습니다.

파일 구성
- index.html: 대시보드 화면
- style.css: 반응형 디자인
- app.js: 필터, 8개 시각화, 검색·정렬, CSV 저장
- data.js: 프로그램별_재원.xlsx에서 추출한 32개 항목

사용법
1. 부문과 회계구분을 선택하면 모든 차트·지표·표가 함께 바뀝니다.
2. 부문 선택 시 해당 부문의 회계구분만 표시됩니다.
3. 그래프에 마우스를 올리면 상세 금액이 표시됩니다.
4. 상세 내역에서 프로그램명·구분을 검색하거나 숫자 열을 눌러 정렬합니다.
5. CSV 다운로드는 현재 필터·검색·정렬 결과를 저장합니다.
